# Basecalling

Included in this directory is a representative bash script for haplotype phasing the ONT sequencing data for this study.

Given the basecalled, modcalled, trimmed, and aligned BAM files used in this study, any haplophased files can be generated by adjusting the path variables at the top of the file and running the following:

```bash
bash haplophase.sh
```

## Important settings
The following settings are encoded in the scripts themselves and mentioned in the manuscript, but are placed here for ease of reference:
* **whatshap version**: `2.6`
* **reference genome**: `chm13v2.0.fasta` (T2T assembly v2.0)
* **VCF file source**: https://hgdownload.soe.ucsc.edu/gbdb/hg38/platinumGenomes/
